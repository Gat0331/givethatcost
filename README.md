# Batch Costing

A responsive, client-side ingredient costing and profit calculator in Philippine pesos (PHP). No framework or build step is required.

## Use locally

Open `index.html` in a browser; it redirects directly to the ingredient calculator. You can also open `calculator.html`.

Add ingredients with an amount and cost per unit, then set the batch yield and selling price. The calculator shows total ingredient cost, cost per item, expected batch revenue, gross profit, and gross margin. All entered amounts are treated as Philippine pesos; there is no currency conversion.

## Publish with GitHub Pages

The site is published at <https://gat0331.github.io/givethatcost/>. Its source is in the public repository <https://github.com/Gat0331/givethatcost>.

The workflow in `.github/workflows/pages.yml` automatically publishes changes pushed to `main`. The public site and source code are visible to everyone.
